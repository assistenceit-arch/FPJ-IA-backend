**FLUJO OPERATIVO — DAÑO EN BIEN AJENO O DEL ESTADO CORE V1**

OBJETIVO

Definir el orden lógico, operativo, narrativo y procedimental que debe seguir el sistema para analizar, validar y redactar informes relacionados con procedimientos de daño en bien ajeno.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL. Este documento agrega ÚNICAMENTE las etapas propias de este delito.

# ETAPA — ORIGEN DEL PROCEDIMIENTO

Identificar cómo inició el procedimiento (Ejemplo: flagrancia observada directamente, alerta de la comunidad o del propietario/entidad afectada).

# ETAPA — DATOS DEL BIEN DAÑADO

Establecer, por cada víctima (propietario del bien): descripción del bien, mecanismo del daño, valor estimado si se conoce, y si el bien pertenece a un particular o al Estado (identificando la entidad propietaria en este último caso).

# ETAPA — REGISTRO PERSONAL Y HALLAZGO

Identificar forma de abordaje y forma de registro. Si el instrumento usado para causar el daño fue recuperado e incautado, precisar el lugar exacto del hallazgo, con su lateralidad — mismo estándar del CORE TRANSVERSAL. Esto no es obligatorio para completar el informe.

# ETAPA — CIERRE Y PUESTA A DISPOSICIÓN

Igual que en el resto de módulos (ver CORE TRANSVERSAL): cadena de custodia de los elementos incautados si los hay, autoridad competente, hora de puesta a disposición y control de demora.
