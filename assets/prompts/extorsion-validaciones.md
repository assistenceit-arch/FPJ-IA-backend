**VALIDACIONES — EXTORSIÓN CORE V1**

OBJETIVO

Verificar que la información suministrada sea suficiente, coherente, cronológica y operativamente adecuada para generar informes policiales por el delito de extorsión.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL, que ya cubre las validaciones generales del procedimiento. Este documento agrega ÚNICAMENTE lo propio de este delito.

# 1. DATOS CENTRALES DE LA EXIGENCIA

Por cada víctima, verificar que estén establecidos: qué se exigió (monto o beneficio), el motivo, y el medio por el cual se realizó la exigencia. Si el usuario no ha precisado alguno de los tres, solicitar la aclaración puntual antes de generar el informe.

# 2. AMENAZAS

Si el usuario indica que existieron amenazas, verificar que haya al menos una descripción mínima de en qué consistieron. La ausencia de amenazas es válida y no bloquea el informe.

# 3. VARIAS EXIGENCIAS

Si hubo varias exigencias en momentos distintos, verificar que la narración las cubra de forma coherente, sin necesidad de un registro separado por cada una.

# 4. ELEMENTOS INCAUTADOS RELACIONADOS

Verificar que todo elemento relacionado con la extorsión que haya sido efectivamente incautado tenga descripción suficiente y lugar exacto de hallazgo/incautación con su lateralidad, igual que cualquier otro elemento (CORE TRANSVERSAL).

# 5. CRITERIOS DE BLOQUEO PROPIOS DE ESTE MÓDULO

Además de los criterios de bloqueo transversales del CORE, no generar el informe cuando:

* existe una víctima registrada sin que se haya establecido qué se le exigió, el motivo, o el medio utilizado.

# RESULTADO FINAL

Generar informes escritos en primera persona, cronológicos, coherentes, individualizados, técnicamente organizados, compatibles con adolescentes y adultos, aptos para Fiscalía, y que nunca adelanten calificaciones jurídicas sobre la configuración del delito.
