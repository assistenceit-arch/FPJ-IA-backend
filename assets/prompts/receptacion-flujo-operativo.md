**FLUJO OPERATIVO — RECEPTACIÓN CORE V1**

OBJETIVO

Definir el orden lógico, operativo, narrativo y procedimental que debe seguir el sistema para analizar, validar y redactar informes relacionados con procedimientos de receptación.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL, que ya define las etapas generales (contexto operativo, ubicación y entorno, origen del procedimiento, abordaje, identificación, comunicaciones, actuaciones posteriores). Este documento agrega ÚNICAMENTE las etapas propias de receptación, que reemplazan a la etapa de "hallazgo" específica de otros módulos.

# ETAPA — ORIGEN DEL PROCEDIMIENTO Y VERIFICACIÓN DEL REPORTE

Identificar cómo inició el procedimiento y, en particular, cómo se estableció que el elemento tenía reporte de hurto:

* si fue por consulta en un aplicativo policial, identificar cuál aplicativo y, si está disponible, el número de reporte encontrado;
* si fue por denuncia de un tercero, identificar el número de la denuncia, la entidad ante la cual fue presentada, y los datos de quien la presentó si los aportó.

# ETAPA — VÍCTIMA (SI EXISTE)

Establecer si fue posible identificar a la víctima original del hurto. Lo más común es que no exista o no se identifique — esto es válido y no requiere justificación adicional. Si excepcionalmente se identifica, documentarla con el mismo estándar de Hurto.

# ETAPA — REGISTRO PERSONAL Y HALLAZGO

Identificar forma de abordaje, forma de registro, y lugar exacto del hallazgo del elemento con reporte de hurto, con su lateralidad — mismo estándar del CORE TRANSVERSAL. Describir el elemento con el mayor detalle disponible.

# ETAPA — CIRCUNSTANCIAS DEL CONOCIMIENTO

Si el usuario relata circunstancias relevantes para establecer si el indiciado sabía o debía saber el origen ilícito del bien (por ejemplo, precio notoriamente inferior, forma de adquisición, actitud al ser cuestionado), incorporarlas al relato de forma objetiva, sin calificar jurídicamente si configuran o no el elemento subjetivo del delito.

# ETAPA — CIERRE Y PUESTA A DISPOSICIÓN

Igual que en el resto de módulos (ver CORE TRANSVERSAL): cadena de custodia del elemento incautado, autoridad competente, hora de puesta a disposición y control de demora.
