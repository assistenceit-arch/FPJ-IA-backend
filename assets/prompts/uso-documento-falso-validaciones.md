**VALIDACIONES — USO DE DOCUMENTO FALSO CORE V1**

OBJETIVO

Verificar que la información suministrada sea suficiente, coherente, cronológica y operativamente adecuada para generar informes policiales por el delito de uso de documento falso.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL, que ya cubre las validaciones generales del procedimiento. Este documento agrega ÚNICAMENTE lo propio de este delito.

# 1. CONTEXTO Y CRITERIOS OBLIGATORIOS

Verificar que estén establecidos: el contexto en que el documento fue exhibido, y los criterios de sospecha que llevaron al funcionario a presumir su falsedad. Si el usuario no ha precisado alguno de los dos, solicitar la aclaración puntual antes de generar el informe.

# 2. NO SE DETERMINA TÉCNICAMENTE LA FALSEDAD

El informe nunca concluye técnicamente que el documento es falso — solo consigna los indicios observados. El sistema no bloquea el informe por la ausencia de un peritaje técnico.

# 3. ELEMENTO INCAUTADO

Verificar que el documento incautado tenga descripción suficiente y lugar exacto de hallazgo, igual que cualquier otro elemento (CORE TRANSVERSAL).

# 4. CRITERIOS DE BLOQUEO PROPIOS DE ESTE MÓDULO

Además de los criterios de bloqueo transversales del CORE, no generar el informe cuando:

* existe un documento señalado como falso sin contexto de exhibición ni criterios de sospecha establecidos.

# RESULTADO FINAL

Generar informes escritos en primera persona, cronológicos, coherentes, individualizados, técnicamente organizados, compatibles con adolescentes y adultos, aptos para Fiscalía, y que nunca adelanten determinaciones técnicas ni calificaciones jurídicas.
