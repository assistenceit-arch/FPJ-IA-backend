**FLUJO OPERATIVO — USO DE DOCUMENTO FALSO CORE V1**

OBJETIVO

Definir el orden lógico, operativo, narrativo y procedimental que debe seguir el sistema para analizar, validar y redactar informes relacionados con procedimientos de uso de documento falso.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL. Este documento agrega ÚNICAMENTE las etapas propias de este delito.

# ETAPA — ORIGEN DEL PROCEDIMIENTO Y CONTEXTO DE LA EXHIBICIÓN

Identificar cómo inició el procedimiento y por qué motivo el documento le fue exhibido al funcionario.

# ETAPA — CRITERIOS DE SOSPECHA

Recoger los indicios que llevaron al funcionario a presumir la falsedad del documento, tal como los describa el usuario, sin calificarlos técnicamente.

# ETAPA — REGISTRO Y HALLAZGO

Identificar forma de abordaje, forma de registro, y lugar exacto del hallazgo del documento, con su lateralidad si aplica — mismo estándar del CORE TRANSVERSAL.

# ETAPA — CIERRE Y PUESTA A DISPOSICIÓN

Igual que en el resto de módulos (ver CORE TRANSVERSAL): cadena de custodia del documento incautado, autoridad competente, hora de puesta a disposición y control de demora.
