**VALIDACIONES — TRÁFICO DE MONEDA FALSA CORE V1**

OBJETIVO

Verificar que la información suministrada sea suficiente, coherente, cronológica y operativamente adecuada para generar informes policiales por el delito de tráfico de moneda falsificada.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL, que ya cubre las validaciones generales del procedimiento. Este documento agrega ÚNICAMENTE lo propio de este delito.

# 1. CONTEXTO Y CRITERIOS OBLIGATORIOS

Verificar que estén establecidos: el contexto de la intercepción (en particular, si el dinero estaba siendo usado activamente en una transacción comercial), y los criterios de sospecha que llevaron al funcionario a presumir su falsedad. Si el usuario no ha precisado alguno de los dos, solicitar la aclaración puntual antes de generar el informe.

# 2. NO SE DETERMINA TÉCNICAMENTE LA FALSEDAD

El informe nunca concluye técnicamente que el dinero es falso — solo consigna los indicios observados. El sistema no bloquea el informe por la ausencia de un peritaje técnico.

# 3. ELEMENTO INCAUTADO

Verificar que el dinero incautado tenga descripción suficiente (denominaciones, cantidad, valor nominal) y lugar exacto de hallazgo, igual que cualquier otro elemento (CORE TRANSVERSAL).

# 4. CRITERIOS DE BLOQUEO PROPIOS DE ESTE MÓDULO

Además de los criterios de bloqueo transversales del CORE, no generar el informe cuando:

* existe dinero señalado como falso sin contexto de intercepción ni criterios de sospecha establecidos.

# RESULTADO FINAL

Generar informes escritos en primera persona, cronológicos, coherentes, individualizados, técnicamente organizados, compatibles con adolescentes y adultos, aptos para Fiscalía, y que nunca adelanten determinaciones técnicas ni calificaciones jurídicas.
