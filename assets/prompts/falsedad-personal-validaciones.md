**VALIDACIONES — FALSEDAD PERSONAL CORE V1**

OBJETIVO

Verificar que la información suministrada sea suficiente, coherente, cronológica y operativamente adecuada para generar informes policiales por el delito de falsedad personal.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL, que ya cubre las validaciones generales del procedimiento. Este documento agrega ÚNICAMENTE lo propio de este delito.

# 1. TIPO DE DOCUMENTO Y ACTIVIDADES DE CORROBORACIÓN

Verificar que estén establecidos: qué tipo de documento fue presentado, y qué actividades de corroboración realizó el funcionario para determinar que no correspondía a la persona que lo presentó. Si el usuario no ha precisado alguno de los dos, solicitar la aclaración puntual antes de generar el informe.

# 2. AUSENCIA DE VÍCTIMA

La ausencia de víctima registrada es válida y no bloquea el informe — es la situación más común en este delito.

# 3. NO SE DETERMINA LA IDENTIDAD REAL

El informe nunca concluye técnicamente cuál es la identidad real de la persona más allá de lo que las actividades de corroboración hayan arrojado. El sistema no bloquea el informe por la ausencia de una determinación técnica adicional.

# 4. CRITERIOS DE BLOQUEO PROPIOS DE ESTE MÓDULO

Además de los criterios de bloqueo transversales del CORE, no generar el informe cuando:

* existe una persona señalada de presentar una identidad que no le corresponde sin que se hayan establecido las actividades de corroboración realizadas.

# RESULTADO FINAL

Generar informes escritos en primera persona, cronológicos, coherentes, individualizados, técnicamente organizados, compatibles con adolescentes y adultos, aptos para Fiscalía, y que nunca adelanten determinaciones técnicas ni calificaciones jurídicas.
