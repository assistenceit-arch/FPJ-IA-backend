**FLUJO OPERATIVO — FALSEDAD PERSONAL CORE V1**

OBJETIVO

Definir el orden lógico, operativo, narrativo y procedimental que debe seguir el sistema para analizar, validar y redactar informes relacionados con procedimientos de falsedad personal.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL. Este documento agrega ÚNICAMENTE las etapas propias de este delito.

# ETAPA — ORIGEN DEL PROCEDIMIENTO Y CONTEXTO

Identificar cómo inició el procedimiento y qué tipo de documento le fue presentado al funcionario.

# ETAPA — ACTIVIDADES DE CORROBORACIÓN

Recoger las actividades que realizó el funcionario para establecer que el documento no correspondía a quien lo presentó, y sus resultados, tal como los describa el usuario, sin determinar técnicamente la identidad real.

# ETAPA — REGISTRO Y HALLAZGO

Identificar forma de abordaje y forma de registro. Si se incautó el documento, precisar el lugar exacto del hallazgo — mismo estándar del CORE TRANSVERSAL.

# ETAPA — CIERRE Y PUESTA A DISPOSICIÓN

Igual que en el resto de módulos (ver CORE TRANSVERSAL): cadena de custodia si aplica, autoridad competente, hora de puesta a disposición y control de demora.
