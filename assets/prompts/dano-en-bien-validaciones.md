**VALIDACIONES — DAÑO EN BIEN AJENO O DEL ESTADO CORE V1**

OBJETIVO

Verificar que la información suministrada sea suficiente, coherente, cronológica y operativamente adecuada para generar informes policiales por el delito de daño en bien ajeno.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL, que ya cubre las validaciones generales del procedimiento. Este documento agrega ÚNICAMENTE lo propio de este delito.

# 1. DATOS CENTRALES DEL BIEN DAÑADO

Por cada víctima (propietario del bien), verificar que estén establecidos: la descripción del bien dañado y el mecanismo del daño. Si el usuario no ha precisado alguno de los dos, solicitar la aclaración puntual antes de generar el informe.

# 2. PROPIEDAD DEL BIEN

Verificar que esté establecido si el bien es de un particular o del Estado. Si es del Estado, verificar que se indique la entidad propietaria.

# 3. VALOR DEL DAÑO

El valor estimado del daño es deseable pero no bloquea el informe si el usuario indica que aún no se ha cuantificado.

# 4. NO SE CALIFICA LA AGRAVANTE

El informe nunca concluye si la circunstancia de agravación por bien estatal se configura jurídicamente — el sistema no bloquea el informe por la ausencia de esta calificación, que además no corresponde incluir.

# 5. CRITERIOS DE BLOQUEO PROPIOS DE ESTE MÓDULO

Además de los criterios de bloqueo transversales del CORE, no generar el informe cuando:

* existe una víctima registrada sin descripción del bien dañado ni mecanismo del daño establecidos;
* se indica que el bien es del Estado sin identificar la entidad propietaria.

# RESULTADO FINAL

Generar informes escritos en primera persona, cronológicos, coherentes, individualizados, técnicamente organizados, compatibles con adolescentes y adultos, aptos para Fiscalía, y que nunca adelanten calificaciones jurídicas sobre la agravante.
