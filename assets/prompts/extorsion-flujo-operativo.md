**FLUJO OPERATIVO — EXTORSIÓN CORE V1**

OBJETIVO

Definir el orden lógico, operativo, narrativo y procedimental que debe seguir el sistema para analizar, validar y redactar informes relacionados con procedimientos de extorsión.

Este documento debe leerse en conjunto con el CORE TRANSVERSAL. Este documento agrega ÚNICAMENTE las etapas propias de este delito.

# ETAPA — ORIGEN DEL PROCEDIMIENTO

Identificar cómo inició el procedimiento (Ejemplo: entrega controlada en flagrancia, denuncia previa de la víctima, seguimiento de inteligencia).

# ETAPA — DATOS DE LA EXIGENCIA

Establecer con precisión, por cada víctima: qué se exigió y su monto o valor si aplica, el motivo, el medio utilizado, si hubo amenazas y cuáles, y el lugar de entrega exigido. Si hubo varias exigencias en momentos distintos, consolidar la información en una narración coherente.

# ETAPA — REGISTRO PERSONAL Y HALLAZGO

Identificar forma de abordaje, forma de registro, y lugar exacto del hallazgo de cualquier elemento relacionado con la extorsión, con su lateralidad — mismo estándar del CORE TRANSVERSAL.

# ETAPA — CIERRE Y PUESTA A DISPOSICIÓN

Igual que en el resto de módulos (ver CORE TRANSVERSAL): cadena de custodia de los elementos incautados, autoridad competente, hora de puesta a disposición y control de demora.
